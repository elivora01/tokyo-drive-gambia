CINEMATIC HERO MOTION

==================================================

Create a premium cinematic automotive animation.

The uploaded car artwork is a flattened image, so DO NOT attempt to incorrectly cut the vehicle out.

Instead create the cinematic effect through layered animation:

- Slow camera push-in

- Subtle background zoom

- Subtle horizontal parallax

- Very slight foreground movement

- Elegant gold light streaks

- Soft atmospheric particles

- Subtle light sweep

- Text fade/stagger animation

- CTA entrance animation

- Smooth page-load reveal

The car should feel as though it is arriving/moving into the scene.

Create a subtle "car coupling" visual effect:

1. Background fades into view.

2. Gold atmospheric lighting begins.

3. Vehicle composition gently moves forward.

4. Camera subtly pushes toward the vehicle.

5. Gold light sweep passes behind/around the vehicle.

6. Vehicle settles into its final position.

7. Headline and CTA appear smoothly.

The effect must feel like a premium automotive commercial.

Do NOT:

- make the car fly

- make the car spin

- distort the vehicle

- shake the screen

- overuse particles

- use cheesy animations

- create excessive glowing effects

Respect prefers-reduced-motion.
